The fixed original holdout deep Hit@5 is 0.85 for both English and Korean;
Korean-to-English code is 0.70. On the larger, synthetic sensitivity corpus,
Korean fast Hit@5 is 0.50 versus deep 0.85, with conditional gold-candidate
recall 0.56. The latter reuses inspected labels and is not a new blind holdout.

The optimized 21-distinct-query ARM benchmark has median fast CLI wall time
21.580 s, inference 11.665 s, sampled RSS p95 736,336 KiB. The plan's 15 s
wall and 10 s inference goals are **not met**; the 1.5 GiB memory goal is met.
The benchmark corpus is repetitive synthetic text and the measured p95 varied
substantially. Batch size 4 was slower in a three-query development comparison,
so the default remains batch 1. The latest fitting change preserved the entire
original holdout JSONL byte-for-byte.

The implementation and verification deliverables above are present, but the
missed usability goals and Korean fast candidate recall cannot be described as
passing. `docs/implementation-plan.md` §7.2 explicitly calls for reporting
failed targets and obtaining a scope decision rather than lowering goals
silently. The user chose to complete local v0.1 with these measured limits
disclosed. The 15 s/10 s goals have **not** been redefined or marked as met.
